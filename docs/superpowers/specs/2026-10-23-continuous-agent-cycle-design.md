# Continuous agent cycle

Nethra remains one Windows-owned agent with many durable objectives. A wake may reason and use bounded tools, save progress, then explicitly complete, wait for the owner, or schedule another check. The host decides when a proposed wake is valid and keeps low-cost source checks separate from 30B inference. Android reads the same persisted state.

This slice repairs three concrete failures in the existing cycle. Prose-only model responses cannot consume twelve expensive calls or silently claim work; after two attempts Nethra saves a clear owner-input request. A genuine inference/runtime failure reaches the scheduler's durable retry/backoff and error journal. Fresh, authorized Calendar and Gmail metadata can count as evidence for an ongoing monitoring milestone when its content matches the owner's goal, while stale or disconnected source data cannot prove a current check. A monitoring objective with already-completed steps and an unavailable source yields cheaply with an honest source-health summary and a bounded later wake.

Verification uses deterministic mocked 30B responses and real SQLite reopen, then the installed 30B and phone where reachable. The source adapters stay read-only, untrusted source text never becomes instructions, and no new cloud transport, model, or scheduler is added.
